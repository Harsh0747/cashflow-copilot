# Six-Week Pilot Scorecard

| Area | Metric | Target |
|---|---|---:|
| Activation | Both files successfully uploaded | 80% |
| Speed | Median time to first forecast | < 10 min |
| Retention | Businesses active in week 4 | 60% |
| Utility | Recommendations marked useful | 70% |
| Workflow | Suggested actions completed | 40% |
| Forecast | 7-day balance error | < 10% monthly outflow |
| Quality | Material numerical errors in AI summaries | 0 |
| Safety | Messages sent without human approval | 0 |
| Outcome | Pilot users reporting time saved | 70% |

## Weekly review agenda

1. Compare last forecast with actual cash.
2. Review errors and missing events.
3. Check high-risk invoices and outcomes.
4. Record actions completed.
5. Update assumptions for the next period.
6. Capture one product change request and its underlying job.
